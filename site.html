bero.land

Projeto open source em HTML estático para reunir links, apresentação, media kit, projetos e vídeos.

06.

O projeto

Este site nasceu para concentrar, em um único lugar, tudo o que faz parte do universo do Bero: links principais, apresentação pessoal, media kit, projetos, vídeos e contato.

A ideia foi manter a experiência principal em HTML estático, com uma estética mais crua e direta, sem depender de framework para o que realmente importa.

06.1

Como foi feito

  • HTML estático para estrutura, conteúdo e SEO
  • CSS customizado para layout e identidade visual
  • JavaScript leve para idioma, easter egg e troll mode
  • Arquitetura multipágina para separar links, sobre, media kit, projetos, vídeos e contato
06.2

Repositório
